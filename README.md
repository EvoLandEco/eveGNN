# eveGNN
This repository contains all experimental functions and scripts throughout our study to apply various Neural Network ensemble learning approaches on phylogenetic trees, for tree classification and parameter estimation. It serves as a codebase and an archive.

## Dependency
- Optuna >= 3.4.0
- R >= 4.2.1
- Python = 3.8.16
- PyTorch Geometric = 2.4.0
